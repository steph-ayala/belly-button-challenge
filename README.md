# Belly Button Biodiversity Dashboard

## Synopsis

The Belly Button Biodiversity Dashboard is a data visualization project designed to explore microbial diversity found in human navels. Using interactive charts, users can analyze various bacterial cultures sampled from different individuals. The dashboard dynamically updates based on user selection, providing insights into the most common and abundant bacteria present in the dataset.

## Description

This project is an interactive dashboard that visualizes belly button biodiversity data. It includes dynamic bar and bubble charts along with a metadata panel to display demographic information.

## Installation

1. Clone the repository:

`git clone https://github.com/your-username/your-repo.git`

2. Navigate to the project directory:

`cd your-repo`

3. Install dependencies (if applicable):

`npm install  # or pip install -r requirements.txt` (for Python projects)

## Usage

1. Open the index.html file in a web browser.

2. Select a test subject ID from the dropdown menu.

3. View the metadata and interactive charts updating dynamically.

## Features

- Dropdown selection of test subject IDs

- Metadata panel displaying demographic information

- Bar chart showing the top 10 bacteria cultures found

- Bubble chart visualizing all detected bacteria cultures

- Uses D3.js and Plotly.js for data visualization

## File Structure

- index.html - Main HTML structure for the dashboard

- app.js - JavaScript logic for fetching and displaying data

- samples.json - Data source (hosted remotely)
